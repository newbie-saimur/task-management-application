Task Management System

A powerful mini Trello-like application with modern features

Login Register

Features:

  • Create and manage tasks with priorities (Low/Medium/High/Urgent)
  • Set due dates with automatic overdue detection
  • Organize tasks with categories (Study, Personal, Work, etc.)
  • Drag & drop to reorder tasks
  • Filter by status, category, and priority
  • Dashboard statistics with animated counters
  • Pagination for large task lists
  • Dark mode with persistent settings
  • Toast notifications for all actions
  • Secure authentication with session management
  • Real-time updates without page reload
